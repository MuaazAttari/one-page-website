# 🚀 Muaaz Portfolio

A premium, modern, and interactive developer portfolio built using Next.js and Tailwind CSS.

## 🌐 Live Demo
👉 https://one-page-website-psi.vercel.app/

---

## ✨ Features

- ⚡ Modern UI with AI + 3D + Minimal Design
- 🎨 Smooth animations using Framer Motion
- 📱 Fully Responsive (Mobile + Desktop)
- 🌌 Interactive sections (Projects, Skills, Terminal UI)
- 🚀 Fast performance with Next.js

---

## 🧠 Tech Stack

- Next.js
- Tailwind CSS
- Framer Motion
- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/MuaazAttari/one-page-website.git
```

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```
